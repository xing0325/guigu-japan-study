# 日本分区示意图来源

`japan-regions.svg` 改编自 Geolonia 的 [map-full.svg](https://github.com/geolonia/japanese-prefectures/blob/master/map-full.svg)，原图基于 Wikipedia 的[日本地図.svg](https://ja.wikipedia.org/wiki/ファイル:日本地図.svg)。上游声明采用 GNU Free Documentation License（GFDL）；许可全文见 `GFDL-1.3.txt`。许可适用于此地图图形。

本项目修改：按六组学校覆盖范围重新分组、移除原填色以支持交互高亮、增加地区标识与描述、可点击描边；将复合路径拆分为子路径以计算主体轮廓。保留原图的几何形状和变换。冲绳为移位插图，部分离岛省略；用于地区选择，不用于测量距离或行政边界判断。
