这是一份从城市和日常生活出发的日本语言学校探索手帖，也是我参与实际业务的一次前端实践。

## 建议这样看

先选一个城市，感受城市入口和视觉风格；再进入学校清单，尝试关键词与地区筛选，查看学校在地图上的位置，收藏几所感兴趣的学校。这样能完整走过“了解城市 → 找学校 → 看位置 → 留下候选”的路径。

## 我想解决的问题

选学校不只是比较几列数字。我希望读者能把学校放回城市里理解：它在哪里，周边怎样，生活节奏是否适合自己。因此我把展示方式做成可以翻阅和探索的手帖，而不只是堆一个数据表。

## 遇到的问题与当前阶段

把学校清单变成能浏览的产品，需要同时处理学校资料、地理位置和界面表达。当前有待确认的校名，也有数据与落点需要继续核对，不能只因为页面漂亮就把信息当作已经全部验证。

这个前端刚做完，还欠打磨。我希望它先让人愿意开始比较，再继续改进信息准确性、细节反馈和浏览体验；目前不声称它已经完成真实用户转化验证。

资料覆盖与技术细节见下方开发文档。招生条件、课程与费用请以学校官网为准。
