# 龟谷择校 · 日本留学生活手帖

蓝白手帖风格的日本语言学校探索网站，包含发现日本、学校清单和同页学校地图三个 Tab，支持城市与街区筛选、搜索、收藏和学校定位。

线上网站：https://xing0325.github.io/guigu-japan-study/

这是经过整理的静态发布版本。GitHub Pages 从 main 分支根目录发布；更新并推送 main 即会自动发布。

本地预览：`python -m http.server 4173`

地图使用 MapLibre GL JS 与 CARTO / OpenStreetMap 底图。学校资料 53 条，对应原清单 51 条合作记录；1 条校名待确认未落点。学校官网是最新招生信息的最终来源。

影像来源见 `assets/photo-sources.json`；原创生成插画提示词见 `assets/illustrations/PROMPTS.md`；第三方运行库许可见 `vendor/LICENSE.txt`。
