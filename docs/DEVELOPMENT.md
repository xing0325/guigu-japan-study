# 龟谷择校 · 日本留学生活手帖

从城市与生活出发，寻找适合自己的日本语言学校。它不是只按学费和升学率排序的表格，而是一份可以边逛城市、边看学校、边在地图上理解周边生活的交互手帖。

**在线体验：** <https://xing0325.github.io/guigu-japan-study/>

## 可以做什么

- 从东京、京都、大阪等城市切入，先了解生活节奏与街区气质。
- 浏览语言学校清单，按城市、街区和关键词筛选。
- 在列表与地图之间联动，查看学校位置和周边环境。
- 收藏感兴趣的学校，在同一页继续比较。
- 使用独立学校地图，快速理解学校在城市中的空间关系。

## 数据与内容

当前收录 53 条学校资料，对应原始清单中的 51 条合作记录；另有 1 条校名仍待确认，因此未落点。学校官网始终是招生条件、学费和课程信息的最终来源。

- `locations.json`：学校及地点数据。
- `assets/photo-sources.json`：站内照片来源记录。
- `assets/illustrations/PROMPTS.md`：原创生成插画提示词。
- `vendor/LICENSE.txt`：第三方前端运行库许可。

## 技术实现

项目采用原生 HTML、CSS 和 JavaScript，无需构建步骤。地图使用 MapLibre GL JS，并接入 CARTO / OpenStreetMap 底图；字体和 MapLibre 资源均随仓库提供，适合直接部署到 GitHub Pages。

```text
index.html / entrance.*   首页与城市探索
notebook.*                学校手帖、筛选与收藏
map.html / map-style.json 独立学校地图
locations.json            学校与地点数据
locale.js                  界面文案与本地化
assets/                    图片、字体与插画
vendor/                    自托管第三方库
```

## 本地预览

浏览器会通过 HTTP 读取 JSON，因此请使用本地静态服务器：

```bash

```

然后打开 <http://localhost:4173/>。

## 说明

这是经过整理的静态发布版本，适合用于择校前期探索，不构成留学申请或招生建议。

## 地图加载

- 首次进入时直接按筛选结果或指定学校设置视野，避免先加载全国瓦片再跳转。
- `map-style.json` 内联 CARTO 瓦片地址、缩放范围和署名，省去远程 TileJSON 请求；若上游地址调整，需同步此文件。
- 城市圆点使用原生圆图层，地图文字统一字体栈，避免额外的 sprite 与重复字形请求。保留中日文地名切换。
- 学校图层在 `style.load` 时添加，不等待街道底图；地图实例跨标签页复用，收藏或选中学校时避免重复提交全部学校数据。
- 底图超过 6 秒未完成时显示重试入口；重试保留地图视野、筛选和收藏。提示仅在收到成功瓦片且地图空闲后消失，避免空白底图被当作加载成功。
- 地图依然依赖 CARTO 在线服务；网络耗时会随用户地区及缓存变化，本地预览的耗时不能代表所有访问者。

## 学校分布导航

学校地图增加本地 SVG 分区小图：桌面位于右侧，手机位于主地图上方。图形与文字按钮均可切换区域，学校列表、点位和城市选项同步更新；区域和街区选择写入 `region`、`district` URL 参数，支持刷新和浏览器返回。

`notebook.js` 的 `regions` 按当前学校覆盖范围定义六组选区（札幌・函馆、东京周边、京阪神、甲府、福冈周边、冲绳），不按行政大区或学校数量强行均分。新增城市时应同时补全归属和 SVG 高亮范围。区域按钮数量表示该区收录总数，顶部摘要表示当前筛选结果；未收录学校的区域置灰。点击大区或“全日本”清除城市、街区、关键词和仅收藏筛选，日语水平和留学目标保留。

小图使用静态 SVG，不创建额外地图实例或请求在线瓦片；图形来源和许可见 [地图来源](../assets/maps/SOURCES.md)。

选区具有可点击的描边，东京周边额外提供三个密集街区快捷入口。点击地图聚合点通过 `getClusterLeaves` 读取该组完整学校列表，直接选校并定位，不再要求逐层放大；异步结果会在切换筛选、地图实例或选择其他学校后失效。
