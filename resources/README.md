# 公开资源说明

本目录存放可随项目公开的资料。原始文件保留在本地源目录中，未被修改。

## 已公开

### `data/language-schools-public.csv`

- 来源：本地原始工作簿 `龟谷合作语言学校（按地区）.xlsx`。
- 用途：提供地图和学校列表使用的地区、城市、语言学校基础清单，共 51 条记录。
- 脱敏：是。公开副本删除了标题中的内部合作关系表述，并移除了“同上”“不收中国人了”等内部备注；同时补齐了明显缺失的括号。未包含姓名、联系方式、账号、密钥或用户数据。
- 注意：该清单是项目建设时的资料快照，不构成学校状态、招生政策或合作关系的实时声明。公开使用前仍应通过学校官方渠道核验。
